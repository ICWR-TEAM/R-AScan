# 2026-08-21

## Performance — parallel scanner execution (bottleneck fix)
- Replaced the strictly sequential scanner loop in `r_ascan/app.py` with a bounded `ThreadPoolExecutor`; scanners now overlap their network I/O.
- Added `--scanner-workers` CLI flag (0 = auto, `max(--threads, 4)`) with validation; explicit values are respected and capped by the runnable scanner count.
- Kept total request pressure bounded: the shared `RequestBudget` semaphore still caps concurrent transport requests to `--threads` and enforces `--max-requests`.
- Preserved deterministic discovery order of results regardless of completion order and serialized scanner console output via a print lock.
- KeyboardInterrupt now cancels the request budget and shuts the pool down without waiting.

## Precision — per-scanner request accounting
- Added a per-thread scope counter to `RequestBudget` (`begin_scope`/`scope_count`) so each scanner's `request_count` stays precise even while scanners run concurrently and share the global budget.
- `scan_module` now attributes requests through the scoped counter instead of a global-delta subtraction.

## Precision — optimizer `deterministic-risk-v2`
- Rewrote `r_ascan/module/ml_optimizer.py` with an explicit, auditable model:
  - Per-finding score = `severity_base * confidence_factor * status_factor`, rounded to 2 decimals.
  - Bounded noisy-OR aggregation (`1 - prod(1 - score/10)` scaled to 0-100) — monotonic, order-independent, strictly ≤ 100.
  - Cross-result de-duplication by finding id (no double counting).
  - Priority bands, per-severity/per-priority counts, prioritized id list, top finding, and endpoint hotspots.
- Updated the engine identifier to `deterministic-risk-v2`.

## Reporting — more detailed output
- Enriched normalized findings (`r_ascan/core/normalize.py` + `Finding` model) with OWASP Top 10 mapping, representative CVSS v3.1 vector/score, CVE hints, and reference links.
- Added report scan metadata: `scanner_workers`, `generated_at`.
- Expanded the HTML report (`r_ascan/reporting/html.py` + `report_template.html`):
  - New summary cards (Medium/Low, Confirmed/Potential).
  - Risk Overview with Severity, Priority, and OWASP Top 10 breakdown tables.
  - Risk Prioritization Model section with engine, aggregate risk, top finding, and endpoint hotspots.
  - Findings table gained Severity, Priority, and OWASP columns; scanner table gained Category and Requests columns.
  - Detail blocks now include confidence/status, CVSS vector, OWASP, and references.
